**Dangerous Dave in the Haunted Mansion**, rebuilt in C++ to run natively on Windows 10 / 11.

> **No game data included.** You need your own copy of the MS-DOS game (Softdisk release, version 1.12).

### Getting started
1. Download `ddhm-…-windows-x64.zip` below and unzip it anywhere.
2. Extract your copy of the MS-DOS game into the **`Game`** folder (`DAVE.EXE`, `EGATILES.DD2`, `LEVEL01.DD2` …).
3. Start **`DDHM Launcher.exe`** and press **Play**. The first launch creates the `Assets` folder from your files.

Windows may show *"Windows protected your PC"*: click **More info → Run anyway** (the program isn't code-signed).

### What's in this version
- The complete game: all eight levels, every enemy, Frank and the Master, doors and secrets, scoring and extra lives.
- Everything around it from the original: sliding title screen, level intro map, death scenes, game over, high score,
  *continue from level*, the ending, F1 help, F3 key set-up, TAB status window and the developers' debug keys.
- All 24 PC-speaker sound effects, with an optional softer sound.
- Original controls (`Ctrl` jump, `Alt` fire, arrows) plus `Space` / `Z` / `X` and gamepad support.
- 4:3 or square pixels, resizable window and full screen.

The zip contains only this project's code (MIT licence) and SDL3 (zlib licence).
